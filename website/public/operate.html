Plate 07 Operator lastdown

From this checkout

Run the drive. Read the line.

The binary is lastdown. bench prints one Lastdown line and one baseline line. sim prints the Lastdown campaign. ablate walks a fixture directory. prove prints that directory as three claims. handoff stops at the committed punt and writes the package. resume loads that file in a fresh process. quota prints the InGauge reading.

cargo run --offline --bin lastdown -- bench elci/fixtures/token_budget.json
cargo run --offline --bin lastdown -- bench elci/fixtures/quota_limit.json
cargo run --offline --bin lastdown -- sim elci/fixtures/provider_loss.json
cargo run --offline --bin lastdown -- ablate elci/fixtures
cargo run --offline --bin lastdown -- prove elci/fixtures
cargo run --offline --bin lastdown -- handoff elci/fixtures/token_budget.json /tmp/token_budget.continuation.json
cargo run --offline --bin lastdown -- resume elci/fixtures/token_budget.json /tmp/token_budget.continuation.json
cargo run --offline --bin lastdown -- quota elci/fixtures/quota_limit.json

Exit codes

0
The command finished. A disengaged quota reading is a successful reading.
1
The fixture, the snapshot, or the handoff file failed. Invalid quota JSON exits here.
2
The command line was incomplete. The usage string names every verb.

Fixtures

JSON under elci/fixtures uses schema 1 and denies unknown fields. A missing ingauge key defaults to absent, so older fixtures still load. The set is token_budget, quota_limit, provider_loss, punt_loop, context_exhaustion, rate_limit, slow_provider, financial_budget, partial_tool, malformed_response, and uncommitted_changes.

Boundaries this crate keeps

In process

The field ledger is the journal in src/padagonia.rs. Quota parsing uses serde_json on the snapshot the caller supplies. A live provider probe is outside the gate.

On the wire of the package

Continuation bytes, replay checks, and telemetry stay in Rust. Canonical JSON is the object a fresh context resumes from.

Verify before a claim

deliver --spec deliver.toml --strict runs fmt, clippy with warnings denied, and cargo test. Then both benches, from /home/sal/lastdown. prove can support reserve conservation from those fixtures. Punt advantage and amnesia advantage stay unmeasured on this ledger.

This volume

The anthology server is cargo run --offline --manifest-path website/server/Cargo.toml. It listens on 127.0.0.1:8741 and serves website/public.

Work on the library stays in /home/sal/lastdown. That directory is its own git root. Publish only when asked, through kaptaind, with -r /home/sal/lastdown.
