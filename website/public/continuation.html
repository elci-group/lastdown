Plate 03 Continuation LASTDOWN/1

The sealed package

A fresh context resumes from the object.

The package opens with the magic LASTDOWN/1 and schema version 1. Integrity hashes the typed sections. The inspection summary sits outside that hash and is not authoritative. Canonical bytes are serde_json::to_vec of the object. A resume accepts the file when it matches those bytes and the competitive-key scan is clean.

Inside the hash

Typed sections of the continuation: the field evidence a successor needs to continue the drive.

Outside the hash

The inspection summary. It can describe the object. It does not authorise it.

Before the bytes rest

Credential-shaped text is stripped. A restricted artifact is refused when the destination is a foreign trust domain. Ledger bytes at rest are sealed with HMAC-SHA256 over a SHA-256 keystream. The caller supplies the key.

After commit

The store is two-phase. The protocol records the sealed field only after commit succeeds. MemoryStore exposes committed_count_for on the store itself.

File handoff

lastdown handoff runs Kill::ImmediatelyAfterCommit and writes the canonical package. lastdown resume reads that file in a fresh process, with a new sentinel and a new store, and supplies the receiver route from the resume request. Completed gates stay completed. Sequence continues from the artifact count.

On token_budget the stopped handoff has finished two gates. The fresh resume scores: scarce consumed 4 000, scarce lost 0, four artifacts, status score. The full single-process bench of the same fixture scores at scarce consumed 8 000, scarce lost 0, continuation 2 940 bytes.

lastdown handoff elci/fixtures/token_budget.json /tmp/token_budget.continuation.json
lastdown resume elci/fixtures/token_budget.json /tmp/token_budget.continuation.json

What the successor receives

The package and the candidate packet carry evidence, gates, and contradictions. The model key for a route lives on the route the coordinator assigns. Resume supplies receiver-beta-2026-10 from the request. The predecessor’s model key stays off the package.

A drive can be stopped immediately after one committed punt, and a later process can score the field from that file alone.
