Plate 05 Account Quota InGauge JSON

A measured window

The account keeps what it has left.

An InGauge probe or status snapshot can ride on a fixture under ingauge. Lastdown reads that JSON in process. The engaged reading is the tightest integer token window. A missing measurement stays disengaged. It is never treated as zero capacity, and the drive stays on its token budget.

Which samples count

Token metrics engage. Other shapes stay off the window.
ReadingResult
Metric absent, tokens, or remaining_tokens, with an integer remainingA sample. The smallest remaining wins.
remaining absent or null, and both used and limit are integerslimit − used, saturating at zero.
Null remaining with no integer pair, or a fractional remainingUnmeasured. The snapshot stays disengaged.
A request quota, including a tight request windowIgnored. It is a different scale.
Headroom, utilisation, and tokens per minuteIgnored. The parser keeps integers.
A remaining of zero that is a real integerEngaged. Zero is a measurement.

The parser walks data, snapshots, bridge records, and a nested ingauge object, so lastdown quota can read a fixture file as well as a bare envelope. Invalid JSON exits 1. A disengaged reading exits 0.

One campaign, one account

When the window is present, provider_quota on the grant is that remaining amount, and the hold on that dimension is min(reserve, remaining). Each step’s quota cost equals its scarce cost, so the token accounting on the scarce dimension stays the number the bench already prints. A later possession in the same campaign receives the quota still left on the account. It does not receive a fresh full window.

On quota_limit the token grant is 20 000, so a baseline that ignores the snapshot can finish four steps of 2 000 and score. Lastdown takes one step, banks that gate, and punts. Later possessions see 2 500 remaining with a hold of 800, so ordinary quota is 1 700 and the next 2 000 step does not fit. Neutrals accumulate to reassessment. The lastdown line reports quota_remaining=2500.

quota engaged=true provider=groq remaining=4500 limit=10000 samples=1

A fresh process re-reads whatever snapshot it is given. The continuation object itself is unchanged: token_budget still seals at 2 940 bytes, and that fixture’s quota_remaining stays absent.
